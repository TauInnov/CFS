12.7. תרגול מסכם#

שתי שאלות שמשלבות כלים מסעיף 9.7 ומשבוע 12. שאלה 1 עוסקת בהולכת שגיאות. שאלה 2 היא שאלה מלאה שמתחילה בתיאור פיזיקלי ומסתיימת בקוד: מודל של גוף מתקרר, χ² של המודל מול מדידות, ובחירת הפרמטר הטוב ביותר מתוך רשימת ערכים. לכל שאלה יש תא עבודה ופתרון מלא בהמשך. נסו לפתור לבד לפני שאתם פותחים את הפתרון.

import numpy as np
import pandas as pd

g = 9.8
df = pd.read_csv("lab_measurements.csv")
df_clean = df.dropna()

12.7.1. שאלה 1#

עבור זווית 15 מעלות: חשבו את הממוצע ‎v0_mean‎ של המהירות ההתחלתית ואת שגיאת הממוצע ‎v0_sem‎. אחר כך חשבו את הטווח התאורטי ‎R = v0**2/g * sin(2*theta)‎ עבור ‎v0_mean‎, ואת השגיאה שלו ‎dR‎ לפי הולכת השגיאות מסעיף 9.7:

\[\Delta R = \left|\frac{dR}{dv_0}\right| \Delta v_0, \qquad \frac{dR}{dv_0} = \frac{2 v_0 \sin(2\theta)}{g}\]

כאשר \(\Delta v_0\) היא שגיאת הממוצע ‎v0_sem‎. מהו הטווח התאורטי, בצורה ‎R ± dR‎?

# question 1: your code here

פתרון

angle1 = 15.0
theta1 = np.radians(angle1)
sub1 = df_clean[df_clean["angle_deg"] == angle1]

v0_mean1 = sub1["v0_measured"].mean()
v0_sem1 = sub1["v0_measured"].std(ddof=1) / np.sqrt(len(sub1))

R1 = v0_mean1**2 / g * np.sin(2*theta1)
dR_dv0_1 = 2 * v0_mean1 / g * np.sin(2*theta1)
dR1 = abs(dR_dv0_1) * v0_sem1

print(f"R = {R1:.3f} +/- {dR1:.3f} m")

הטווח התאורטי בזווית 15 מעלות הוא \(R = 21.0 \pm 0.6\) מטר.

12.7.2. שאלה 2#

גוף מתקרר בחדר בטמפרטורה של 20 מעלות. בכל דקה ההפרש מטמפרטורת החדר מוכפל ב-\((1-k)\), ולכן אחרי \(n\) דקות הטמפרטורה היא

\[T_n = 20 + (T_0 - 20)(1-k)^n\]

הטמפרטורה נמדדה בכמה זמנים: המערך ‎minutes‎ מכיל את זמני המדידה בדקות, המערך ‎T_meas‎ את הטמפרטורות שנמדדו, ו-‎dT‎ את שגיאת המדידה (מספר אחד לכל המדידות, או מערך עם שגיאה לכל מדידה). השלימו את שלוש הפונקציות בתא הבא, לפי הסדר. אם לא פתרתם סעיף, הניחו שהפונקציות מהסעיפים הקודמים עובדות כמתואר, והמשיכו.

א. ‎model(T0, k, minutes)‎ מחזירה את הטמפרטורה אחרי ‎minutes‎ דקות. הפונקציה עובדת גם כאשר ‎minutes‎ הוא מערך של זמנים.

ב. ‎chi2_of(k, T0, minutes, T_meas, dT)‎ מחזירה את χ² של המודל מול המדידות, כלומר את הסכום של ‎((T_meas - model(T0, k, minutes)) / dT)**2‎ על כל המדידות.

ג. ‎best_k(k_values, T0, minutes, T_meas, dT)‎ מחזירה את הערך מתוך ‎k_values‎ שעבורו χ² הקטן ביותר.

פתרון

def model(T0, k, minutes):
    """Temperature (deg C) after minutes; minutes can be an array."""
    return 20 + (T0 - 20) * (1 - k)**minutes


def chi2_of(k, T0, minutes, T_meas, dT):
    """chi2 of the model with T0 and k against T_meas with errors dT."""
    return np.sum(((T_meas - model(T0, k, minutes)) / dT)**2)


def best_k(k_values, T0, minutes, T_meas, dT):
    """The value in k_values with the smallest chi2."""
    best = k_values[0]
    best_chi2 = chi2_of(best, T0, minutes, T_meas, dT)
    for k in k_values:
        c = chi2_of(k, T0, minutes, T_meas, dT)
        if c < best_chi2:
            best = k
            best_chi2 = c
    return best


print(model(60.0, 0.5, minutes_test))   # [60. 40. 30.]
print(chi2_of(0.5, 60.0, minutes_test, T_test, 1.0))   # 2.0
print(best_k([0.4, 0.5, 0.6], 60.0, minutes_test, T_test, 1.0))   # 0.5

  • א. עם ‎k = 0.5‎ ההפרש מטמפרטורת החדר, 40 בהתחלה, מוכפל ב-0.5 בכל דקה: \(20 + 40 = 60\), אחר כך \(20 + 20 = 40\) ואחר כך \(20 + 10 = 30\). החזקה ‎(1 - k)**minutes‎ פועלת על כל איבר של המערך ‎minutes‎, ולכן אותה שורה עובדת גם על מספר וגם על מערך.

  • ב. השאריות הן ‎0, 1, -1‎, וכל אחת מחולקת ב-‎dT = 1‎, ולכן \(\chi^2 = 0 + 1 + 1 = 2\).

  • ג. עבור ‎k = 0.4‎ מתקבל χ² של 38.16, עבור ‎k = 0.5‎ של 2, ועבור ‎k = 0.6‎ של 31.76; הקטן ביותר הוא של ‎k = 0.5‎. הלולאה שומרת ב-‎best‎ את הערך עם χ² הקטן ביותר עד כה, כמו הסריקה בסעיף 12.2. דרך אחרת היא לבנות מערך של כל ערכי χ² ולבחור בו את המיקום של הקטן ביותר עם ‎argmin‎, כמו בסריקה במערך בסעיף 12.2:

def best_k(k_values, T0, minutes, T_meas, dT):
    """The value in k_values with the smallest chi2."""
    chi2_all = np.array([chi2_of(k, T0, minutes, T_meas, dT)
                         for k in k_values])
    return k_values[chi2_all.argmin()]
